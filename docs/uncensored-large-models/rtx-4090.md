# 2×RTX 4090 실행 요약

기본 선택은 Qwen3.6-27B FP8입니다. MoE의 낮은 활성 파라미터와 MTP를 비교하려면 35B-A3B, GGUF와 큰 KV 여유가 필요하면 Agents-A1을 사용합니다.

## 선택 순서

1. 범용·멀티모달: `qwen27`
2. MoE·tool calling: `qwen35`
3. dense 40B GGUF: `qwen40-q6`
4. agentic GGUF: `agents-a1-quality`
5. 118B/128B 저비트 연구: `laguna118-mini`, `mistral128-iq2m`

118B와 128B가 파일상 적재된다는 사실은 실용적인 속도나 품질을 뜻하지 않습니다. 로컬 기본 모델은 Qwen3.6 두 종 중에서 고르는 것이 맞습니다.

## Qwen3.6 FP8

```bash
cd docs/uncensored-large-models
export API_KEY='replace-with-a-long-random-secret'
MODEL=qwen27 PROFILE=4090x2 ./scripts/serve_qwen36_fp8.sh
```

35B-A3B:

```bash
MODEL=qwen35 PROFILE=4090x2 ./scripts/serve_qwen36_fp8.sh
```

2×4090에서는 MTP와 pipeline parallel 조합이 vLLM 버전에 따라 실패할 수 있어 35B의 MTP를 기본으로 끕니다. 강제로 시험하려면 `ENABLE_MTP=1`을 추가하되 시작 실패 시 다시 끕니다.

## GGUF

```bash
MODEL=qwen40-q6 GPU_COUNT=2 ./scripts/serve_gguf.sh
MODEL=agents-a1-quality GPU_COUNT=2 PORT=8081 ./scripts/serve_gguf.sh
```

한 번에 실행할 명령은 하나입니다. 같은 GPU 두 장에서 두 서버를 동시에 시작하지 않습니다.

## 메모리 부족 시

1. 다른 GPU 프로세스를 종료합니다.
2. `MAX_MODEL_LEN=8192` 또는 `4096`으로 낮춥니다.
3. 동시 요청을 1개로 유지합니다.
4. GGUF는 `FIT_TARGETS`를 GPU별 예약 MiB로 늘립니다. 예: `FIT_TARGETS=3072,3072`.
5. 그래도 실패하면 Laguna/Mistral 실험 모델 대신 Qwen3.6 또는 Agents-A1을 사용합니다.

자세한 크기와 대형 GPU 구성은 [하드웨어 매트릭스](hardware-matrix.md)를 참고합니다.
