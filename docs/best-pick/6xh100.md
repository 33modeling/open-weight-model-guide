# 6×H100 80GB — 최고 성능 픽

> 기준일: 2026-08-03 · 명목 VRAM 480GB (NVLink/NVSwitch)

## 결론

**GLM-5.2 (753B/40B) — W4A8 399.7GB**가 6×H100에서 적재 가능한 가장 강한 오픈웨이트다. 단, 잔여가 약 80GB뿐이라 8×H100처럼 긴 context를 넉넉히 잡을 수 없고, **TP=6을 지원하지 않는 모델이 많아 배포 전 확인이 필수**다(미지원 시 TP=2×PP=3).

## 순위와 적합성

| 순위(성능) | 모델 | 포맷 · 가중치 | 6×H100 적합성 |
|---:|---|---|---|
| 1 | **GLM-5.2 (753B/40B)** | **W4A8 · 399.7GB** | **○ 권장 픽 — 잔여 ~80GB, TP=6 확인** |
| 2 | Qwen3.5-397B-A17B | FP8 · 406.2GB | △ 경계 — 잔여 ~74GB, 짧은 context 한정 |
| 3 | MiniMax-M3 (428B/23B) | FP8 · 약 430GB | ✗ 잔여 ~50GB — KV 공간 부족 |
| — | MiniMax-M2.7 (230B/10B) | FP8 · 230.1GB | ◎ 안정 픽 — TP=2 복제본 3개 |
| — | Kimi K2.6 / K2.7 (1T) | Native INT4 · 595.2GB | ✗ 불가 |

## 용도별 추천

- **최고 품질**: GLM-5.2 W4A8 — TP=6 지원 확인 후, 컨텍스트 32K부터 검증.
- **안정 운영·처리량**: MiniMax-M2.7 FP8 TP=2 × 3 replicas — 6장 구성에서 divisibility 문제 없는 안전한 기본값.
- **판단 기준**: 긴 context·대형 픽이 목표면 2장을 더해 8×H100로 가는 편이 선택지가 훨씬 넓다. ([best-pick 8×H100](8xh100.md))
